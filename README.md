# Ruling

When VAR checks a goal, Ruling has the explanation ready in seconds: the evidence computed from the data, the exact Law, how similar calls went this season, and a checked message for the stadium, the league's match centre, broadcasters and fans in their own language.

Built on synthetic, football-realistic data with fictional clubs and players.

Work in progress. The evaluation was pre-registered before any data or prompts existed: [docs/eval-plan.md](docs/eval-plan.md).
